[ PROBLEM ]

  • Harsh Field Sensor Failures: Extreme weather causes frequent electrical spikes, dead flatlines, and calibration drifts in AWS stations.
  • Flawed Static Thresholds: Simple rule-based filters miss slow sensor degradation and raise false alarms during real storms.
  • Black-Box ML Lacks Diagnostics: Standard models output boolean True/False without pinpointing which sensor failed or why.
  • Forecasting Data Pollution: Delayed manual quality screening allows bad data into Numerical Weather Prediction (NWP) models.

[ Our Solution ]

An Agentic AI-powered AWS diagnostics pipeline that:

  • Ingests Real-Time Telemetry: Streams 10-minute multi-parameter readings (T, P, RH) across AWS stations.
  • Two-Tier Hybrid Detection: Checks thermodynamic boundary rates (ΔT > 5°C/10min) alongside Isolation Forest ML.
  • LangGraph Agentic Diagnostics: 6-node state machine computes SHAP feature attributions and root-cause narratives.
  • Non-Destructive Baseline Correction: Computes physical correction baselines without overwriting raw records.
  • Autonomous Action & Alerting: Sends instant HTML alerts with prescriptive action plans for field technicians.

Why Different

  • Physics-Coupled: Separates real storms from hardware faults via thermodynamic coupling.
  • SHAP Explainable: Quantifies exact feature contribution scores.
  • Agentic Action: Autonomously dispatches alerts instead of passive logging.

Key Value Proposition

  • 99%+ Meteorological Trust: Pristine inputs for weather & disaster models.
  • Faster MTTR: Prescriptive repair actions cut troubleshooting time.
  • Zero DB Lock-in: In-memory speed (<15ms) with pluggable storage.
